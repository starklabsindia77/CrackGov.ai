# Study Streaks

Track daily study activity and maintain learning streaks

## Version

1.0.0

## Category

analytics

## Permissions

None

## API Routes

- `GET /api/study-streaks`
- `POST /api/study-streaks/log`

## Navigation

- My Streak (`/app/streak`)

## Configuration

See `config.schema.ts` for configuration options.

## Installation

```bash
POST /api/admin/plugins/study-streaks/install
POST /api/admin/plugins/study-streaks/enable
```
