# AI Doubt Resolution

AI-powered doubt resolution with step-by-step explanations and subject-specific tutoring

## Version

1.0.0

## Category

ai

## Permissions

- `doubt-chat:ask` - Ask doubts
- `doubt-chat:view` - View doubt history

## API Routes

- `POST /api/ai/doubt`
- `GET /api/doubts/history`

## Navigation

- Ask Doubt (`/app/doubts`)

## Configuration

See `config.schema.ts` for configuration options.

## Installation

```bash
POST /api/admin/plugins/doubt-chat/install
POST /api/admin/plugins/doubt-chat/enable
```
