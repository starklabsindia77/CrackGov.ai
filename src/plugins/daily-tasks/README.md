# Daily Tasks & Goals

Manage daily study tasks and track goal completion

## Version

1.0.0

## Category

core

## Permissions

None

## API Routes

- `GET /api/daily-tasks`
- `POST /api/daily-tasks`
- `PUT /api/daily-tasks/:id/complete`
- `DELETE /api/daily-tasks/:id`

## Navigation

- Daily Tasks (`/app/tasks`)

## Configuration

See `config.schema.ts` for configuration options.

## Installation

```bash
POST /api/admin/plugins/daily-tasks/install
POST /api/admin/plugins/daily-tasks/enable
```
