# Bookmarks & Notes

Save bookmarks and create notes for questions, tests, and study materials

## Version

1.0.0

## Category

core

## Permissions

None

## API Routes

- `GET /api/bookmarks`
- `POST /api/bookmarks`
- `DELETE /api/bookmarks/:id`
- `GET /api/notes`
- `POST /api/notes`
- `PUT /api/notes/:id`
- `DELETE /api/notes/:id`

## Navigation

- My Notes (`/app/notes`)

## Configuration

See `config.schema.ts` for configuration options.

## Installation

```bash
POST /api/admin/plugins/bookmarks-notes/install
POST /api/admin/plugins/bookmarks-notes/enable
```
