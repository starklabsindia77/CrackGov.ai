# PDF Export

Export study plans, test results, and reports as PDF

## Version

1.0.0

## Category

integration

## Permissions

None

## API Routes

- `POST /api/pdf/study-plan/:id`
- `POST /api/pdf/test-result/:id`
- `POST /api/pdf/report`

## Navigation

None

## Configuration

See `config.schema.ts` for configuration options.

## Installation

```bash
POST /api/admin/plugins/pdf-export/install
POST /api/admin/plugins/pdf-export/enable
```
